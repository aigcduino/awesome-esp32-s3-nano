## 先读这一段

WT9932S3-NANO 是一块超小尺寸的 Nano 规格开发板，主控 **ESP32-S3R8**：

- **主控** —— ESP32-S3R8，Xtensa LX7 双核 @240MHz，384kB ROM + 512kB SRAM
- **存储** —— 16MB Flash + 8MB PSRAM
- **无线** —— 2.4GHz Wi-Fi 与 Bluetooth LE，支持 USB HID
- **供电** —— 工作电压 3.3V，外部输入 5V，可走 VIN、VBUS 或 Type-C
- **按键** —— 板载 BOOT 与 RESET
- **边缘** —— **半孔焊盘**，可直接焊到自己板子上做产品
- **工具链** —— Arduino、MicroPython、ESP-IDF，兼容 Arduino IoT Cloud

它和 Arduino Nano ESP32 引脚一一对应，这正是这个列表的价值所在：

| | WT9932S3-NANO | Arduino Nano ESP32 |
|---|---|---|
| 主控模组 | ESP32-S3R8 | u-blox NORA-W106（ESP32-S3） |
| Flash | 16MB | 16MB |
| 引脚布局 | 完全一致 `D0–D13` / `A0–A7` | 参照 |
| 半孔焊盘 | 有 | 无 |

两个直接结论：

1. **IDE 里选 `Arduino Nano ESP32` 就能用。** 烧录走 DFU（`2341:0070`），和官方[入门指南](https://wiki.wireless-tag.com/docs/zh/WT9932S3-NANO/getting_started.html)里的日志完全一致。
2. **内存配置本来就是对的。** Espressif 核心的 `nano_nora` 板定义就是 16MB Flash + OPI PSRAM，所以板载 8MB PSRAM 开箱可用，**不需要**自己写板变体或改分区表。

### 引脚定义

`D0–D13` / `A0–A7` 是 Arduino 引脚名，**不是** GPIO 编号。下面是官方文档给的对应关系：

| 左排针 | GPIO | 右排针 | GPIO |
|---|---|---|---|
| D13 | GPIO48（SPI SCK） | D12 | GPIO47（SPI MISO） |
| 3.3V | — | D11 | GPIO38（SPI MOSI） |
| B0 | GPIO46 | D10 | GPIO21 |
| A0 | GPIO1 | D9 | GPIO18 |
| A1 | GPIO2 | D8 | GPIO17 |
| A2 | GPIO3 | D7 | GPIO10 |
| A3 | GPIO4 | D6 | GPIO9 |
| A4 | GPIO11（I2C SDA） | D5 | GPIO8 |
| A5 | GPIO12（I2C SCL） | D4 | GPIO7 |
| A6 | GPIO13 | D3 | GPIO6 |
| A7 | GPIO14 | D2 | GPIO5 |
| VBUS | 5V | GND | — |
| B1 | GPIO0（BOOT） | RST | — |
| GND | — | D0 | GPIO44（RXD） |
| VIN | 5V | D1 | GPIO43（TXD） |

## 快速开始

Arduino IDE：装 **esp32** 板包（Espressif 出的），然后选 **Arduino Nano ESP32**。

PlatformIO：

```ini
[env:nano]
platform = espressif32
board = arduino_nano_esp32
framework = arduino
```

arduino-cli：

```bash
arduino-cli core install esp32:esp32
arduino-cli compile --fqbn esp32:esp32:nano_nora .
```

## 烧录前必看

- **烧录走 DFU，不是普通串口。** 强制进下载模式：按住 **BOOT**（GPIO0）→ 点一下 **RESET** → 松开 BOOT。
- **`D0–D13` / `A0–A7` 不是 GPIO 编号。** 板定义里有 `PinNumbers` 菜单（`By Arduino pin` / 原生 GPIO），以上表为准。抄别人代码不核对这个，就是"代码没错但就是不工作"的头号原因。
- **默认分区只给 APP 3MB**（`app3M_fat9M_fact512k_16MB`）。16MB 的芯片不等于 16MB 的应用，塞字库或模型得自己写分区表。
- **`loop()` 跑在 core 1**（`ARDUINO_RUNNING_CORE=1`），按 core 0 假设写的双核代码会翻车。
- **USB 默认是 HW CDC**（`usb_mode=0`、`cdc_on_boot=1`）。切成 HID 后串口会"消失"，这是正常的。
- **板子文档在厂商 wiki，不在 GitHub** —— [wiki.wireless-tag.com](https://wiki.wireless-tag.com/docs/zh/WT9932S3-NANO/board_features.html)（功能、引脚、入门指南、规格书 PDF）。厂商 GitHub 组织是 [`Wireless-TAG-Maker`](https://github.com/Wireless-TAG-Maker)。
